# Repository Working Rules

## In-game testing

- Do not launch, automate, or interact with Quasimorph to test mods from this repository.
- Build-time checks, static inspection, decompilation, and log/report analysis are allowed.
- Ask the user to perform in-game checks and provide a short test procedure plus the exact log or report files needed for diagnosis.
- Do not create, overwrite, move, or delete Quasimorph save slots as part of testing.
